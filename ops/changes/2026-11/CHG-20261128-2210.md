# CHG-20261128-2210: Phase 11 — realistic performance targets + daily/weekly goal tracker

Owner set a 10%/day target; project lead rejected as unachievable (compounds past global market capacity in a year, forces ~100% risk per trade vs the 4% stop). Phase 11 replaces that with evidence-based FROZEN bands from our own backtest.

- india_trader/performance_targets.py (S11.1): FROZEN daily/weekly/monthly bands for Rs 15k from the measured EMA 9/15 backtest. classify_day/week/month -> GREEN/FLAT/RED/STOP_HIT/NO_DATA. Dataclass frozen; altering a band requires visible code change. Owner cadence (4-7 trades/day) classified separately (NONE/UNDER/ON_TARGET/OVER).
- deploy/daily_goal_check.py (S11.2): reads monitor feed -> writes goal_check.json + one-line verdict. Safe on empty data.
- deploy/weekly_report.py (S11.4): Mon-Fri reconciliation; per-day + per-strategy breakdown; classifies against weekly band.
- claude/phase-11-performance-targets.md: phase plan + growth path (Rs 15k -> Rs 50k gate on >=10 green-band sessions, etc.).
- Tests: tests/test_performance_targets.py, tests/test_daily_goal_check.py, tests/test_weekly_report.py. Suite 536 green.
- Rollback: git revert. Paper only; no live-trade changes.
