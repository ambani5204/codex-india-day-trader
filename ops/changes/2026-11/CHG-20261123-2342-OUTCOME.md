# CHG-20261123-2342 — Outcome and outstanding release gates

## Implemented (isolated draft PR #62, not integrated into production)
- `deploy/phase0_fenced_events.py`: atomic Firestore REST `documents:commit` with a CAS write to the canonical owner lease and immutable `paper_events_v1` create-if-absent, both in one transaction/batch. Strict CE/PE options-only event types and paper mode, version/market/date/owner/strategy/expiry checks, write-once event IDs, finite quantities/prices and after-cost P&L. No raw `INDEX_SIGNAL` as executable event.
- GET-only `verify_persisted_event()` checks full private document payload and original lease lineage after lost ACK without retrying the write. Absent/mismatched/malformed remote data does not count as a verified event.
- Preflight `_verify_open_before_close()` rejects missing/mismatched opening event, session ID, owner lease, strategy, contract, quantity or spread hedge before accepting simulated option exit. **This GET preflight is NOT a transactionally protected open-event read set** and cannot alone prevent privileged deletion after the read.
- `tests/test_phase0_fenced_events.py`: in-memory atomic Firestore fake; simultaneous writers, duplicate event ID, stale owner, expiry, unknown ACK after actual commit, missing/incorrect P&L/taxes, hedged credit, orphan close, wrong open session/contract and GET recovery. No network, secrets or real orders.
- `docs/assumptions.md`: ASM-011 records gaps and the need for deterministic producer IDs and complete downstream fencing.

## Gates NOT verified
- **No production integration**: existing legacy paper workers, sidecars, `journal_write`, `firebase_live_publisher.publish_history` and `publish` remain unchanged, so they DO NOT use this fencing adapter.
- **No real Firebase CAS or source/backend ledger verification**: tests are synthetic atomic responses, not a credentialed live Firestore proof, not source journal ↔ Firestore equality and not an options P&L audit.
- No atomic open-event read set (preflight alone cannot make foreign-key existence transactional), no fencing of all publishers/recovery, no stable producer event IDs for existing strategy workers, no exchange-day 15:30 terminal proof.
- Current prototype supports one owner generation and **refuses takeover** without complete journal reconciliation. Automatic restart/resume after an interrupted paper session remains blocked; this is intentional to avoid duplicate fills.
- No tested production `rollback --to CHG-20261123-2342` or complete Android/signed APK rollback. Therefore keep draft, no merge or production data writes.
- No live orders, historical cleanup/backfill, risk increases, new strategy thresholds or artifacts containing trade data.
