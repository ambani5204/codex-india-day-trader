## Revision after independent review (same CHG, still draft)
- Workers now start in their own session/process group, and the whole group (grandchildren included) is SIGKILLed on timeout, lost lease, exception or SIGTERM. Fencing protects the queue, and this prevents a second agent running on the same task's side effects.
- `stale_refused` audit events are now saved after the rollback. Previously the rollback discarded them.
- A lost lease is recorded as `stale` (not as a failed attempt), and the watchdog reassigns the task.
- Added a `recover` CLI command (cron watchdog fallback when no dispatcher is alive) and a `requeue` command (human action for `failed`). `stuck_ids()` lists tasks that are dependents of failed tasks. The `add_task` idempotency check now compares max_attempts and priority too. Worker output is decoded with `errors="replace"`.
- Known limitation: leases use wall-clock time. A clock step can expire a live lease early, and the worker is then killed and fenced out (never run twice). Crash recovery is still tested with an injected clock, not by killing a dispatcher process.
