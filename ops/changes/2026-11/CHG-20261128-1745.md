# CHG-20261128-1745: monitor data feed (journals -> monitor_data.json)

- deploy/monitor_feed.py: reads the day's *.jsonl paper journals (any sidecar/ledger shape) and emits the monitor UI's data.json: day net P&L / trades / win rate, per-strategy P&L, recent signals, closed-trade history, and status (NO_SESSION/RUNNING/COMPLETE). Tolerant of malformed lines and missing fields; reports only what journals contain (no invented trades/prices).
- Feeds the Algobani Paper Monitor artifact, which fetches data.json and falls back to a clearly-marked SAMPLE when absent.
- Tests: tests/test_monitor_feed.py. Rollback: git revert.
